## Required comparison procedure

1. Download each source image from its pinned URL and verify its recorded SHA-256 before use. Record actual filename, byte length, digest, attribution and license.
2. Review the source image for crop, perspective, lens distortion, occlusion and viewpoint. Do not infer a hidden facade from a visible view.
3. Select the matching deterministic render and record both source-image and render hashes in the review record.
4. Compare normalized visible silhouette and feature locations first: overall outline, roofline, dome/drum, portico/stair centreline, bay/opening rhythm and side-wing junctions. Keep camera/view mismatch separate from geometry mismatch.
5. For every proposed correction, record the observed evidence, affected parameters, confidence class, expected visual effect and before/after render hashes.
6. Rebuild all LOD GLBs and regenerate the same 13 fixed views. Re-run model, geometry, texture and manifest validation on the new model hash.
7. Keep publication blocked until the final-head CI passes, visual defects have an evidence-backed disposition, and dimensional accuracy is supported by independent measurements/control points. Published dimensions alone are not independent survey evidence.
