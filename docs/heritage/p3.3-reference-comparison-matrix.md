## Verification protocol

1. Keep source, model, render-manifest, QA-report and reference-pack hashes tied together; never reuse an old report for a new model hash.
2. For each visible mismatch, record: reference ID/hash, candidate render ID/hash, camera/view mismatch, observed feature, proposed parameter/mesh, confidence class, and before/after hashes.
3. Repair degenerate/topology defects by source geometry or documented intentional-open-surface classifications, not by removing warnings from the report.
4. For a roof correction, do not infer scale or measured elevations from the unrectified aerial image. Preserve [E]/[?] labels until supported by reliable measurement.
5. Rebuild all LOD assets, rerun geometry/texture QA, and regenerate all 13 deterministic views after model changes.
6. Require the latest CI run on the exact current PR head to complete green, followed by review of the exact final render evidence, before any promotion.
