# Picked entity resolution\n\n`Scene.pick` can return an Entity, an object whose `id` is an Entity or string, or a primitive object with an Entity/string ID. This helper normalizes those shapes to the canonical entity in the data source currently being queried.\n\nThe helper is deliberately stateless. It does not decide which feature layer wins a click, read feature properties, change selection state, request rendering, or own the data source.\n\nRun `npm run test:picked-entity-resolution` for direct runtime tests of each supported pick shape and the adapter delegation boundary.\n
