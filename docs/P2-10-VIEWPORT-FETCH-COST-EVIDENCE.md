The controlled `scripts/benchmark-viewport-cold-warm.mjs` run records the first valid viewport request after a fresh production-server start, followed by five identical requests on the same process. It requires index bytes to be read in the first request, zero index bytes in the repeated requests, and identical ordered feature hashes. The P2.10 API correctness test reports its observed cache state without assuming it owns the server’s first valid request; the browser workload also records observed index bytes and cache-miss count because the cache may already be warm.
