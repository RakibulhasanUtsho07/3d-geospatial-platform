# Feature pick routing\n\nThe feature-pick router preserves the existing click target priority: nearby-place point, property-listing point, mapped road, then Overture building polygon. Candidate lookups are lazy, so a higher-priority match prevents lower-priority source lookups.\n\nThe router has no access to `CesiumAdapter` state. The adapter continues to own selection clearing, active selection, navigation paths, feature metadata, and listener emission.\n\nRun `npm run test:feature-pick-routing` for the routing priority and short-circuit regression tests.\n
