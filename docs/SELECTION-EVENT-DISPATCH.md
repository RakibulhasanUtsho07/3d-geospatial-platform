# Selection listener dispatch\n\n`dispatchSelectionListeners` applies one shared try/catch contract to feature, nearby-place, road, and property selection listeners. Listener sets are iterated directly, preserving their existing insertion and live-mutation behavior. One failing subscriber is reported via the callback, and dispatch continues to remaining listeners.\n\nThe adapter keeps separate error messages for each selection channel, and continues to own selection state and cleanup order. The dispatcher is intentionally unaware of Cesium, map layers, rendering, or selection state.\n\nRun `npm run test:selection-event-dispatch` for dispatcher behavior and adapter cleanup-order regressions.\n
