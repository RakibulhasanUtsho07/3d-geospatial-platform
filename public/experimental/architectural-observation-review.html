Architectural observation review studio

Annotate rooflines, domes, arches, windows, columns and other visible architectural features directly on one source photo. Each observation records original-image pixel coordinates, visibility, confidence and source/view provenance. Review decisions keep an append-only history.

This tool records human observations; it does not recognize buildings, create ground truth, estimate metric dimensions or approve publication. A “reviewed” item is an operator attestation only. Keep occluded, not-visible and not-detected states explicit instead of inventing hidden architecture.
